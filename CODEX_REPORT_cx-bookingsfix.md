## Сохранённое поведение и решения

- Пациент видит короткий результат записи; календарь OneLink остаётся источником истины. Форматы Staff Copilot, API и UI не менялись.
- Новые записи Captain сохраняют `source = 'captain'`. Старые ссылки на provider status в описаниях не удалялись; принудительный вызов пациентом даёт нейтральный ответ.
- Удержание уведомлений оставлено только для записи MedElement с ожидаемой командой; выпуск происходит лишь после успеха точной `create_reception`. Транзакция вокруг внешней работы не добавлялась.
- Миграций, удаления данных, новых зависимостей и изменений `config/brakeman.ignore`, `codex-input/`, en/kk или UI нет. `docs/` в этом клоне не инициализирован; новых пользовательских текстов и контрактов не добавлено.
